On the captured 549 KB 1TamilMV homepage, median desktop parse and anchor scan fell from 79.8 ms to 17.2 ms; returning cached rows took under 1 ms. Home remained responsive during emulator navigation; the Metro log still contains a general VirtualizedList performance warning. Some 1TamilMV links are expired (the first Jailer embed explicitly reported deletion or expiry), and one Lulu mirror did not resolve in DNS. Those links need upstream replacements. No WAF solver was needed for the working movie samples. For FXShare, the 403 cause was not isolated to a cookie, device fingerprint, or IP; native playback would require a verified Android media response.
